# ReleaseTruth brand assets

ReleaseTruth uses a dark evidence-console visual language with a light-blue signal accent. The mark represents two release paths entering a shared verification point.

Files:

- `releasetruth-mark.svg` — square icon suitable for docs/social/repository use
- `releasetruth-wordmark.svg` — horizontal mark + ReleaseTruth name

Primary UI tokens used by the dashboard:

```text
background  #070b14
panel       #101827
text        #e8edf8
muted       #8fa0ba
accent      #7dd3fc
good        #5ee6a8
warning     #ffd166
breaking    #ff7189
```

Do not encode compatibility meaning through color alone; text labels and severity names must remain visible.
