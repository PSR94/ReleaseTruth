# Roadmap

## v0.1 — deterministic behavioral diff foundation

- behavior.lock v1 schema and migration boundary
- normalization, canonicalization, hashing, diffing, classification, scoring
- CLI capture/compare/report/baseline/history/blame MVPs
- API, browser, accessibility, CLI, events, and lightweight performance adapters
- TruthShop regression demo
- HTML/JSON/Markdown/JUnit/SARIF reports
- GitHub Actions integration
- FastAPI service and Next.js dashboard

## Later

- native GitHub App
- GitLab support
- gRPC/GraphQL/mobile/database adapters
- distributed workers
- richer source correlation and behavioral coverage
- plugin SDK and adapter marketplace
- optional AI explanation providers, always downstream of deterministic evidence
