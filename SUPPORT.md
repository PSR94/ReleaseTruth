# Support

Use GitHub Discussions for usage questions and design conversations once enabled. Use GitHub Issues for reproducible bugs and feature requests. Security-sensitive reports belong in private vulnerability reporting, not public issues.

When requesting help, include:

- ReleaseTruth version or commit
- operating system and architecture
- relevant `.releasetruth.yml` excerpt with secrets removed
- exact command and exit code
- smallest useful capture/report artifact after redaction

ReleaseTruth is pre-1.0 software; compatibility expectations are documented in `docs/reference/versioning.md`.
